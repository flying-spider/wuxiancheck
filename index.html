代理设置

在「供应商」选择代理源： · 91代理：填「提取链接」（返回 ip:port:时间 文本，链接需含 format=text&sep=1&time=1）， 可选填代理账号/密码做账密认证； · rox代理：填主机、端口、账号、密码，切换 IP 时随机化账号中 sessid 字段的后 8 位 （大小写+数字），IP 默认按 5 分钟寿命处理。 后台会持续拉取代理并用「质量检测网址」检测 IP 质量；网址留空时不检测域名， 仅判定代理 TCP 可达即入池。网址填 vivo 业务站（https://userappeal.vivo.com.cn/#/index） 时，还会额外探测验证码源站 captcha.vivo.com.cn 并校验页面含「vivo账号申诉」， 仅当响应耗时低于延迟阈值才算优质 IP；若 vivo 域名被代理出口屏蔽（CONNECT 403）， 可改填一个可访问的网址（如 https://www.baidu.com/）来只检测隧道连通性； 若代理返回 407（需要认证），请在「代理账号/密码」中填写 91http 的账密， 或用白名单验证；池满 N 个即暂停拉取，低于 N 自动补充；当前 IP 到期前 5 秒自动换新； 查询时若 getSliderUrl 返回风控（账号存在风险），会自动换 IP 并刷新页面重试； 「直连模式」开启后，浏览器与 curl_cffi 转发均不走 91http 代理，直接用本机 IP 访问（此时不会拉取代理池，也不会自动换 IP）；适合排查代理是否拖慢访问。 「仅 getSliderUrl 走动态代理」开启后，只有风控闸口请求 getSliderUrl （/userappeal/v1/getSliderUrl）经本地 curl_cffi + 91http 动态代理转发， 其余请求（页面、静态资源、验证码图片）全部直连本机 IP； 风控自动换 IP 依然生效（检测 getSliderUrl 返回的短密文），并与「直连模式」互斥。 「使用 curl_cffi 中转」开启时浏览器请求经本地 MITM 代理做 TLS 指纹伪装， 关闭时浏览器直连上游代理（不伪装指纹），可对比验证码加载效果； 「验证码域名直连」开启后，captcha.vivo.com.cn（含 JS、接口与 p1/p2 图片） 绕过代理直接访问源站，可显著加快验证码弹出与图片加载，但页面与验证码会来自不同 IP， 极少数情况下顶象风控可能因 IP 不一致而拒绝，如遇失败请关闭该开关。 「自动换 IP」关闭后，到期与风控都不再自动切换，也不再自动补池， 只有手动点击「刷新」时才主动获取一个代理并应用； 开启后会自动补池，手动「刷新」改为直接从池中取（不主动拉取）， 可设置「最大自动切换数量」，达到上限即停止自动切换，重新勾选会自动清零计数。
